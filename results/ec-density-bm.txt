=========================================================================
 Non-density of E(Q) in E(Q_p) as a Brauer-Manin obstruction
=========================================================================

(1) The general statement.
    Br_1(E)/Br_0(E) = H^1(Q, Pic E-bar) = H^1(Q, E), and for beta in
    H^1(Q,E) the invariant of the corresponding Brauer class at a local
    point is the LOCAL TATE PAIRING <Q_v, beta_v>_v.  Reciprocity,
    sum_v <Q, beta_v>_v = 0 for Q in E(Q), is global duality.  So
    'Tate pairing + reciprocity' and 'Brauer-Manin' are one argument.
    Manin's theorem: if Sha(E) is finite then the Brauer-Manin set is
    EXACTLY the closure of E(Q) in the adelic points.  Both curves below
    have analytic rank 1, so Gross-Zagier + Kolyvagin make Sha finite and
    the theorem applies unconditionally to them.

(4) What a quaternion class can and cannot reach.

    A class of order 2 in Br(E) cuts out a subgroup of index at most 2, so
    it can only ever explain an index-2 failure.  The examples of
    ec-padic-closure.typ with larger index need classes of larger order:

      curve (conductor)          p    total index   order needed   comment
      [0, 0, 1, -1, 0] (37)      23      2        2      quaternion algebra suffices
      [0, 0, 1, -1, 0] (37)      59      4        4      needs order 4: NOT a quaternion algebra
      [1, 1, 1, -1, 0] (89)      11      11        11      needs order 11: NOT a quaternion algebra
      [0, 1, 1, 0, 0] (43)      43      2        2      quaternion algebra suffices

    The index-11 failure at conductor 89, p = 11 -- the formal-group layer
    E_1/E_2 -- therefore cannot be seen by ANY quaternion algebra.  Manin's
    theorem still applies (Sha is finite there), so a Brauer class of order
    11 does the job, but it is not an algebra one writes down by hand.
    The moral: BM explains all of it, but the EXPLICIT quaternion story
    reaches exactly the index-2 part -- which is the reduction layer, and
    is where 2-descent lives.

-------------------------------------------------------------------------
(5) Does an index-2 failure require a 2-isogeny over Q?  NO.
    A 2-isogeny over Q means a Galois-stable kernel of order 2, i.e. a
    RATIONAL 2-torsion point.  What the argument actually needs is a class
    of order 2 in Br(E), i.e. a class in H^1(Q, E[2]) -- and full 2-descent
    on E[2] exists for every curve.  The isogeny was only a CONVENIENCE: it
    puts the descent map into Q*/(Q*)^2, so the pairing is a Hilbert symbol
    over Q and the class is one quaternion algebra with CONSTANT entries.
    Without it one works over the cubic etale algebra L = Q[t]/(f), the
    descent map is Q -> X(Q) - theta in L*/(L*)^2, the pairing is
    prod_{w|v} (X(Q)-theta, d)_w over the places of L, and the Brauer class
    is the CORESTRICTION cor_{L(E)/Q(E)} (d, X - theta) -- still unramified,
    since div(X-theta) = 2(T_theta) - 2(O) is even and corestriction
    preserves that, and still of order 2.  It is simply not a quaternion
    algebra over Q(E) with constant slots.

    The decisive example is the FIRST curve of these notes:
      E : Y^2 = X^3 - 16X + 16    (conductor 37, the model X = 4x, Y = 8y+4 of y^2+y = x^3-x)
      isogeny class size = 1  -> NO rational isogeny of ANY degree,
      t^3-16t+16 irreducible over Q : 1  -> E[2] irreducible, Galois group S_3.
      Yet the closure of E(Q) in E(Q_23) has index 2 (section 2 of
      ec-padic-closure.typ).  Here is the order-2 class that proves it.

      L = Q(theta), theta^3 = 16 theta - 16 :  disc 148, class number 1, signature [3, 0]
      d = 1/4*x^2 - 2*x - 11   N(d) = 529 = 23^2
        (square norm is exactly the condition for d to lie in
         H^1(Q,E[2]) = ker(N : L*/L*^2 -> Q*/Q*^2))
      the ideal (d) = one prime above 23 of residue degree 2, exponent 1 -- so d is a unit away from 23.

      pairing prod_{w|v} (X(Q)-theta, d)_w on the rational points nP,
      P = (0,4) the saturated generator:
         n     X(nP)          v=oo   v=2   v=23   v=37   product
         1   0            1     1     1      1      1
         2   4            1     1     1      1      1
         3   -4            1     1     1      1      1
         4   8            1     1     1      1      1
         5   1            1     1     1      1      1
         6   24            1     1     1      1      1
         7   -20/9            1     1     1      1      1
         8   84/25            1     1     1      1      1

      the pairing is +1 at v = oo, 2, 37 for EVERY local point (checked by
      scanning X in Q_v with X^3-16X+16 a v-adic square), and at every other
      v it is +1 because v_w(X(Q)-theta) is even outside 2 and the bad
      primes while d is a unit there.  Reciprocity over L then forces the
      v = 23 factor to be +1 at every RATIONAL point -- as the table shows.

      but at X = -1 : X^3-16X+16 = 31, a square in Q_23 (31 = 8 mod 23, a residue),
      so E(Q_23) has a point with X = -1, and there
         prod_{w|23} (X-theta, d)_w = -1
      That 23-adic neighbourhood contains no rational point.

    So: no 2-isogeny, no rational 2-torsion, no isogeny at all -- and still
    an index-2 Brauer-Manin obstruction.  The implication in the other
    direction is what is true: a rational 2-isogeny makes the class a
    single quaternion algebra, which is why sections 2 and 3 look simple.

(6) Index 4 and index 11: n-descent exists for every n, so why are these
    harder?  Three reasons, of increasing severity.

    (i) THE ORDER OF THE CLASS IS FORCED.  The local quotient is cyclic:
      conductor 37, p = 59 : E(F_59) = Z/52 cyclic, ord(Pbar) = 13,
        and 13P is in E_1 but not E_2, so Gamma contains E_1 and
        E(Q_59)/Gamma = Z/52 mod Z/13 = Z/4  -- CYCLIC of order 4.
      conductor 89, p = 11 : reduction is ONTO E(F_11) = Z/14, and 14P lies in E_2,
        so E(Q_11)/Gamma = E_1/E_2 = Z/11  -- CYCLIC of order 11.
      A family of classes of order 2 cuts out a quotient of EXPONENT 2, so
      it can never produce Z/4.  Index 4 needs a class of order 4, index 11
      one of order 11.

      How much does each n-descent see at p = 59?  (E(F_59) is cyclic of
      order 52, Pbar has order 13, so Pbar lies in nE(F_59) iff 52/gcd(n,52)
      is a multiple of 13.)
        n = 2 : E(F_p)/nE(F_p) = Z/2,  image of E(Q) trivial  -> n-descent sees index 2
        n = 4 : E(F_p)/nE(F_p) = Z/4,  image of E(Q) trivial  -> n-descent sees index 4
        n = 13 : E(F_p)/nE(F_p) = Z/13,  image of E(Q) nontrivial  -> n-descent sees index 1
        n = 26 : E(F_p)/nE(F_p) = Z/26,  image of E(Q) nontrivial  -> n-descent sees index 1
        n = 52 : E(F_p)/nE(F_p) = Z/52,  image of E(Q) nontrivial  -> n-descent sees index 1
      so 2-descent already gets a factor 2 of the 4; the last factor 2
      needs 4-descent.  Nothing smaller will do.

    (ii) THE DESCENT ALGEBRA GROWS.  For n = 2 it is the CUBIC etale algebra
      L = Q[t]/(f) -- which is why section 5 fits on a page.  For n = 11:
      conductor 89, deg elldivpol(E,11) = 60 = (11^2-1)/2, and it factors over Q with degrees [60] -- irreducible,
      so nothing collapses.  |GL_2(F_11)| = 13200 bounds [Q(E[11]):Q].
      Also, a degree-n cyclic algebra needs mu_n, and mu_n is in Q only for
      n = 2; for n > 2 one builds over Q(mu_n) and corestricts.

    (iii) WILDNESS AT THE PLACE WHERE DETECTION HAPPENS -- the real wall.
      The n-th norm residue symbol at v is TAME exactly when v does not
      divide n:
        n = 2, v = 59 : tame
        n = 2, v = 2 : WILD
        n = 4, v = 59 : tame
        n = 4, v = 2 : WILD
        n = 11, v = 11 : WILD
      Index 4 at p = 59 : 59 does not divide 4, so the symbol is TAME at
        the place where the class must be non-trivial.  (It is wild at
        v = 2, but there one only needs VANISHING, and that wildness is the
        classical mod-8 kind.)
      Index 11 at p = 11 : n = p.  Wild exactly where detection happens.

      And this is STRUCTURAL, not bad luck.  E_1(Q_p) = Z_p is pro-p, so
      every finite quotient of the formal group is a p-group; cutting
      E_1/E_2 = Z/p always demands a class of order p evaluated at the place
      p.  By contrast E_0/E_1 has order p+1-a_p (good) or p -+ 1 (multiplic-
      ative), prime to p away from anomalous primes -- the tame world.
      So the filtration of ec-padic-closure.typ is also a TAME/WILD
      filtration: the top layers are tame and explicitly reachable, the
      formal-group layer is wild.

    Tooling: PARI's nfhilbert is literally 'X^2 - aY^2 - bZ^2 has a
    solution' -- quadratic only, no exponent argument; Sage's
    hilbert_symbol likewise.  Neither has an n-th norm residue symbol for
    n > 2.  These notes already hit that exact wall in descent-s3.typ,
    which needed a CUBIC norm-residue symbol at the wild place v = 3.
    The index-11 case is the same gap, one prime up: not blocked by
    mathematics, blocked by an unimplemented wild symbol.

(7) Is Brauer-Manin just the n-descents, repackaged?

    For an elliptic curve, essentially YES and the identification is EXACT:
    E-bar is a curve over an algebraically closed field, so Br(E-bar) = 0 by
    Tsen -- an elliptic curve has NO transcendental Brauer group.  Hence
      Br(E) = Br_1(E),   Br(E)/Br_0(E) = H^1(Q,E) = union_n H^1(Q,E)[n],
    and H^1(Q,E)[n] = coker(E(Q)/n -> H^1(Q,E[n])) is exactly the output of
    n-descent.  Nothing is left over.  For a fixed (E,p) one n suffices (the
    exponent of the finite group E(Q_p)/Gamma); across all p you need
    n -> infinity along p-powers, since the formal group is Z_p.

    Three qualifications:

    (1) It is a DUALITY, not a restatement.  Descent cuts down H^1(Q,E[n])
        using the local conditions W_v and bounds the GROUP; Brauer-Manin
        cuts down prod_v E(Q_v) using classes and bounds the CLOSURE.
        The sharpening: A_beta vanishes at every v != p iff beta_v is in
        W_v^perp = W_v there, and detects at p iff beta_p is not in W_p.  So
        the classes that obstruct at p are exactly Sel_n^(p) / Sel_n, the
        Selmer group RELAXED at p modulo the honest one.
        For conductor 37 at p = 23, n = 2 :  ellrank = [1, 1, 0, [[-1, 0]]]
          rank 1, torsion 1, Sha[2] = 0  ->  dim Sel_2 = 1
          and d = theta^2/4 - 2theta - 11 of section 5 lies in Sel_2^(23)
          but not in Sel_2, so dim Sel_2^(23) >= 2.  Whether such a class
          exists is a Greenberg-Wiles computation, not a formality --
          see selmer-local-conditions.typ.

    (2) That the descents see EVERYTHING is a theorem.  closure(E(Q)) is
        contained in the Brauer-Manin set formally (reciprocity); the
        REVERSE inclusion is Manin's theorem and needs Sha finite, proved
        via Poitou-Tate and the Cassels-Tate pairing.  Unconditional here
        only because these curves have analytic rank 1.

    (3) The equivalence is special to E.  Off an abelian variety there is no
        group law, no isogeny and no n-descent, but there is still a Brauer
        group and still sum_v inv_v = 0 -- e.g. the class (2, x+4) on the
        negative Pell conic of integral-bm.typ is not an n-descent class of
        anything.  The packaging buys PORTABILITY; on E it buys nothing new.
