 A Brauer-Manin obstruction to integral points:  x^2 - 34 y^2 = -1
=========================================================================

(1) X(Z) = 0/  for  x^2 - 34 y^2 = -1
    fundamental unit of Z[sqrt 34] : 35 + 6*w   norm = 1
    negative Pell is soluble iff that norm is -1, so: soluble = 0
    brute force 0 <= y <= 200000 : solutions found = 0

(2) X(Z_v) != 0/  for every v
    real: x^2 = 34 y^2 - 1 has real solutions, e.g. y = 1, x = sqrt 33.
    p = 2: take y = 1, x^2 = 33.  33 mod 8 = 1, so 33 is a square in Z_2  ->  point exists.
    odd p < 2000 with no point mod p : []
    X is smooth over Z[1/2]: the gradient (2x, -68y) vanishes mod p
    only if x = 0 and 34y = 0 mod p, which contradicts x^2 - 34y^2 = -1.
    So Hensel lifts every F_p-point, and X(Z_p) != 0/ for all odd p.

(3) the class  A = (2, x + 4)  is unramified on X_Q
    zeros of x + 4 on X:  x = -4,  34 y^2 = 17,  so y^2 = 1/2
    residue field  Q(sqrt(34*(4^2+1))) = Q(sqrt 578)  and 578 = [2, 1; 17, 2]
    squarefree part = 2, so the residue field is Q(sqrt 2)
    is 2 a square there?  1   -> residue at the zeros is trivial
    (this is why C = 4 was chosen:  17*(4^2+1) = 289 = 17^2, a perfect square)
    poles: the single closed point at infinity, residue field Q(sqrt 34).
    is 2 a square in Q(sqrt 34)?  0   -> A is NON-CONSTANT, ramified only at the removed point.

(4) inv_oo A = 0 at every real point
    (a,b)_oo = -1 needs a < 0 AND b < 0, and here a = 2 > 0.
    sample: hilbert(2, -1000, 0) = 1,  hilbert(2, 1000, 0) = 1

(5) inv_2 A = 1/2 at EVERY Z_2-point
    exhaustive over Z/2^10:  2048 solutions
    values of x mod 8 that occur      : [1, 7]
    values of hilbert(2, x+4, 2)   : [-1]
    proof: x^2+1 = 2*17*y^2 forces x odd and y a unit; then
      (x^2+1)/2 = 17 y^2 = 1 mod 8, and (x^2+1)/2 = 5 mod 8 when x = +-3 mod 8,
      so x = +-1 mod 8, x+4 = +-3 mod 8, and (2, +-3 mod 8)_2 = -1.

(6) inv_p A = 0 at every Z_p-point, p odd
    (2, x+4)_p = (2/p)^v_p(x+4), so it is trivial unless
    2 is a non-residue mod p AND v_p(x+4) is odd.
    but x = -4 mod p forces 34y^2 = 17 mod p, i.e. 2y^2 = 1: 2 must be a square.
    p < 5000 where 'p | x+4 is possible' differs from '2 is a QR mod p': []
    so v_p(x+4) >= 1 only when (2/p) = +1, where the symbol is +1 anyway.

(7) sum_v inv_v A  =  0 (oo)  +  1/2 (at 2)  +  0 (odd p)  =  1/2
    X(A_Z) != 0/  but  X(A_Z)^Br = 0/,  hence X(Z) = 0/.
    This is a Brauer-Manin obstruction to an INTEGRAL point,
    on a variety whose rational points are Zariski dense.

(9) the residue of A is the genus character of K = Q(sqrt 34)
    class number h(K) = 2,  class group = [2]
    K has 2 ramified primes, so genus theory gives a 2-rank of 1 in the narrow class group,
    and the genus field is K(sqrt 2) = Q(sqrt 2, sqrt 17), unramified over K.
    residue of A at the point at infinity = class of 2 in K*/K*^2:
      is 2 a square in K?  0  -> the residue is exactly the genus character.
    So this Brauer-Manin obstruction IS the classical genus-theory
    obstruction to x^2 - 34 y^2 = -1, in Brauer clothing.
