cubic-residues.gp -- checks for cubic-residues.typ

For p = 3 and p = 2 mod 3, every residue is a cube: cubing is a
bijection on F_p^*.  Everything below is about p = 1 mod 3.

  (1) 4p = L^2 + 27M^2 for p = 1 mod 3, p < 100000 : 4784 primes,
      no representation 0 times, more than one 0 times

  (2) on the 2556 primes p = 1 mod 3 below 50000:
      2 is a cube mod p  <=>  2 | M     : 0 mismatches
      3 is a cube mod p  <=>  3 | M     : 0 mismatches
      5 is a cube mod p  <=>  5 | L M   : 0 mismatches
      7 is a cube mod p  <=>  7 | L M   : 0 mismatches

  (3) p = x^2 + xy + 61y^2  <=>  3 is a cube  : 0 mismatches of 2556
      3 is a cube for 833 of them; p = x^2 + 243y^2 for only 271,
      and that never fails to imply it (0 counterexamples) -- sufficient,
      not necessary.   h(-243) = 3, h(-972) = 9, h(-108) = 3

      mod 9     : 7 and 61 are both 7 mod 9, and 3 is a cube mod 61 but not mod 7
      mod 27    : 7 and 61 are both 7 mod 27, and 3 is a cube mod 61 but not mod 7
      mod 81    : 31 and 193 are both 31 mod 81, and 3 is a cube mod 193 but not mod 31
      mod 243   : 13 and 499 are both 13 mod 243, and 3 is a cube mod 499 but not mod 13
      mod 729   : 139 and 1597 are both 139 mod 729, and 3 is a cube mod 1597 but not mod 139
  (4) witnesses above: a congruence on p cannot decide the question

  (5) density of { p : 3 is a cube mod p, p = 1 mod 3 } among all primes:
      x = 10^3 :       26 of      166 primes = 0.15663
      x = 10^4 :      191 of     1227 primes = 0.15566
      x = 10^5 :     1582 of     9590 primes = 0.16496
      x = 10^6 :    13044 of    78496 primes = 0.16617
      x = 10^7 :   110695 of   664577 primes = 0.16656
      1/6 = 0.16667
