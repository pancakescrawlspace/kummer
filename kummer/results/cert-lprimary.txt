=========================================================================
 l-primary certificate for the single-place sweep, sections 3.3 and 3.4
=========================================================================

E : v^2 = u^3 + u + 1 (496a).   E_d : Y^2 = X^3 + d^2 X + d^3, minimal
model at p.   E^d(Q_p) = G_p (+) (+)_{l != p} G_l, with G_p = Z_p (the
p-torsion vanishes on every line, cert-ptors.gp) and G_l = T[l^oo] of
order l^v_l(M).   A closed subgroup decomposes the same way, so
     [G : R] = prod_l [G_l : R_l],
and density at p is R_l = G_l for EVERY layer -- independent conditions,
one per layer.  (For the LEDGER of section 2.3 coverage does NOT split
like this: a pair must lie in one and the same entry, so the choice is
coupled across layers.  A single reach has no such coupling.)

One line per (p, d, l).  No discrete logarithms anywhere: a layer index
is an order, not a coordinate, so it needs no base -- which is also why
the ellgroup randomness trap of sections 2.5 and 3.4 cannot arise here.
